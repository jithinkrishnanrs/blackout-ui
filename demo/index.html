BLACKOUT UI

The web, one flashlight beam at a time.

Blackout UI drops a solid black layer over your page and cuts a hole around the pointer. Nothing underneath is repainted, re-themed, or rebuilt — the flashlight just reveals whatever is already there.

Install

Works with a bundler, or straight from a CDN. No configuration required.

npm install blackout-ui
import Blackout from "blackout-ui";

Blackout.init();

Or drop it straight into a page with no build step:

<script src="https://unpkg.com/blackout-ui"></script>
<script>
  BlackoutUI.init();
</script>

What it does — and doesn't do

Framework agnostic

Vanilla JS, React, Vue, Svelte, Next.js, Astro, Angular, static HTML — it's just DOM and CSS underneath.

Zero dependencies

Nothing to audit, nothing to update. The published package ships with an empty dependencies field.

Your theme, untouched

Light mode stays light, dark mode stays dark. Blackout UI never inspects or rewrites your CSS.

Tiny

Under 4KB gzipped for the core build. No canvas, no WebGL, no animation engine.

Doesn't get in the way

Clicks, hovers, forms, drag-and-drop, and keyboard navigation all pass straight through by default.

SSR-safe

Importing the package on the server is a no-op. Nothing touches window until you call a method in the browser.

API

Method Does
init(options?)Mounts the overlay. Safe to call more than once.
configure(options)Updates settings in place, no re-mount.
enable() / disable()Toggle the effect without tearing it down.
toggle()Flip the current enabled state.
destroy()Fully removes the overlay, listeners, and restores the cursor.
setPosition(x, y)Manually move the flashlight.
setRadius/setSoftness/setDarkness(n)Shorthand for configure().
on(event, fn) / off(event, fn)Listen for enable, disable, configure, destroy.

Full option reference and framework examples are in the README.
